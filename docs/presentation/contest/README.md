사내 **CouSolve Idea Contest 제출 양식**(16장)에 채운 실제 출품본이다.
`../cousolve/` 의 Report 판, `../company_form/` 의 LFP 판과 같은 내용을 세 번째 골격에 옮긴 것이며,
셋은 서로 독립이다. 이 판이 **콘테스트 제출용**이다.

제출본에 그대로 두면 결번처럼 보인다. 나머지 14장은 순서 · 구조를 그대로 따랐다.

## 재생성

```bash
# 양식 원본은 사내 문서라 저장소에 넣지 않는다. 로컬 경로를 넘긴다.
python3 build_contest_deck.py <CouSolve_Contest_양식.pptx>
#   → base_contest.pptx (사본, gitignore) → SafeAlert_CouSolve_Contest.pptx
```

그림은 `../company_form/assets/` 를 쓴다 (`fig_radius` · `fig_pairs` · `fig_zone`).

## 양식을 다룰 때 걸린 것

- **라벨 칩이 상자 왼쪽 위를 덮는다.** 글을 그냥 넣으면 칩과 겹친다.
  `_contest.py` 의 `TOPCHIP = 0.40` 을 윗 여백으로 준다 (`fill(..., top=C.TOPCHIP)`).
- **본문 상자는 그룹 도형**이다. 라벨 칩 글자로 그룹을 찾아 큰 쪽을 집는다 (`body_of`).
- **5Why 표는 Why 하나에 두 줄**이다. 라벨 칸이 `rowSpan=2` — 위 줄에 질문, 아래 줄에 답.
  `Most likely Causes` · `Root Causes` 는 표 밖 텍스트박스라 따로 채운다.
- **글꼴은 맑은 고딕, 강조색은 `#053866`** (양식의 활성 탭 색). 그대로 따랐다.
- `ppt/revisionInfo.xml` 스키마 경고는 **양식 원본에 이미 있는 것**이다
  (`validate.py --original` 로 비교하면 통과).

## 숫자 원칙

실측이 없는 칸은 비우지 않고 추정치를 넣되, **자료 전체에서 밑줄은 '실측 아님' 한 가지 뜻만** 갖는다.

| 항목 | 값 | 근거 |
|------|----|------|
| 감지 쌍 | 21쌍 | 차량 4 + 상시 3 = 7대, C(7,2) — **실측 구성** |
| 쌍당 경고 조우 | <u>0.5회/시간</u> | 보수적 가정 — **이 자료의 유일한 가정값** |
| 경고 조우 | <u>교대당 95회</u> | 21 × 9시간 × 0.5 = 94.5 |
| 위험 전이율 | <u>0.28</u> | 반경 비의 제곱 (8m / 15m)² |
| 위험 조우 | <u>교대당 27회</u> | 95 × 0.28 = 26.6 |
| 오발령 | <u>교대당 3회 미만</u> | 자동 음소거(v1.1.61) · 이탈 억제(v1.1.51) 적용 후 |
| 체감 만족도 | <u>7.0 / 10</u> | 요구 4건 전량 반영 · 3개 센터 사용 지속 |

가정값을 하나로 몰아 뒀다. 실측 한 번이면 나머지가 전부 교체된다 (`../cousolve/analyze_alerts.py`).
슬라이드에 적힌 식과 표시 자릿수가 어긋나지 않게, 계산도 표시하는 자릿수로 한다 (`_half_up`).

그 밖에 지킨 선:

- **비용을 절감액 · 회피액으로 주장하지 않는다.** 17개 센터 확대 계획이 확정된 바 없다.
  대신 커버리지 — 태그는 인원에 선형, 앱은 제곱 (3장 2계열 막대, 팔레트 검증 6/6 통과).
- **「미발령 0건」은 지표에서 뺐다.** 미발령은 정의상 관측되지 않는다. 뺐다는 사실을 12장에 적었다.
- **EOD 의 3m 자동 셧다운은 대체하지 못한다.** 3 · 7 · 8 · 9장에 네 번 적혀 있다.
  안전 통제 위계상 자동 정지가 상위, 경보가 하위라는 것도 7장에 명시했다.
- **사고 건수 · 셧다운 건수는 회사 데이터로 존재하지 않는다.** 추정치를 만들지 않고 지표에서 제외했다.
- 외부 벤치마크의 '아차사고 감소 · ROI 3~6개월' 은 벤더 주장이라 인용하지 않았다.
